# adb-file-transfer
A simple ADB-based file transfer tool that enables sending and receiving
files between PC and Android devices using USB debugging.

Features:
- Transfer files from PC to Android
- Transfer files from Android to PC
- Uses ADB (USB Debugging required)
- Simple executable, no installation needed
## Download Instructions
1. Download all files
2. Keep all files in the same folder
3. Extract only the `.001`
4. You will get the original EXE file
